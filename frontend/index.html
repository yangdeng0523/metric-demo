主题域管理 业务领域的高层划分，组织指标与维度

业务过程管理 不可拆分的企业事件，指标定义的基础

原子指标管理 业务过程 + 聚合方式 + 物理字段，不可再拆分

维度管理 观察和分析数据的角度，含维度属性统一定义

派生指标管理 原子指标 + 时间周期 + 统计粒度 + 业务限定（修饰词）

复合指标管理 基于派生指标的四则运算，如客单价 = 支付金额 ÷ 支付笔数

发布审批 指标定义完成后提交发布，经审批同意后正式生效（PUBLISHED）；驳回不改变原状态

逻辑模型管理 物理表 → 逻辑模型，屏蔽底层表结构差异（P1）

下游模型管理 基于逻辑模型 + 指标集合生成 DWS 汇总表，可物化落地（dl_ 前缀）

选择重导对象 模型 / 指标 / 维度更新后，反查下游任务血缘并手动重导（默认近 3 个月）
